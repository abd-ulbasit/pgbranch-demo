pgoverlay-demo

A demo of pgoverlay: branch-per-PR Postgres databases.

This demo is archived. The single-node EKS cluster that ran the pgoverlay stack was torn down in June 2026, so there is no live database to answer from. Nothing here is served from a real branch anymore, and the API paths return 410 Gone rather than pretending otherwise.

The demo showed the failure mode that branch-per-PR databases exist to catch: a migration that passes against an empty local database and fails against real production data.

That run is recorded and still readable: PR #1 — a UNIQUE (email) migration that was green locally, then hit 37 legacy duplicate signups on a masked copy-on-write clone of an 80k-user / 400k-order production database. The PR comments carry the actual error and the fix. That, not this page, is the artifact.

Those comments say pgbranch, which is what this project was called when the run happened. They are the bot's own output from a real run, so they are left exactly as posted rather than rewritten to match the later name.

  • PR #1 — the recorded run: branch created, migration failed on real data, fixed, branch destroyed on merge
  • Source — the app, migrations, and the CI wiring that drove it
  • pgoverlay — the tool itself, which is maintained

Running it yourself: the endpoints under /api still work against a real pgoverlay install — point PGOVERLAY_HOST/PGOVERLAY_PORT/PGPASSWORD at it and set DEMO_LIVE=true.
