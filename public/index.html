pgbranch-demo

Every pull request on this repo gets its own disposable, PII-masked clone of the production database — created in seconds by pgbranch running on EKS. This deployment is connected to the database branch matching its git context.

  • /api/db — which branch am I on, and what's in it?
  • /api/users — signup volume
  • /api/stats — top customers by lifetime spend
  • POST /api/signup — idempotent signup (writes stay in this branch)

Previews answer from postgres@pr-<N>; production answers from postgres@main-stable.
